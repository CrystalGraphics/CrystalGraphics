# render — recorded drawing, and where it draws

> Root guide: [`CrystalGraphics/AGENTS.md`](../../../../../../../AGENTS.md)

## What This Package Is

The engine's drawing model: draws are recorded into chunks and passes, built into a frame and executed on the render
thread. The root holds what every recorder shares; each sub-package is one layer of it.

| Type or package | Role |
|------|------|
| `CgRenderer` | Drawing outside the world: `executeNow(recording)` builds and executes a recording at once (a preview, a bake, a test); `drawNow(chunk, camera, order)` is an immediate canvas's flush into the current target; `clear` and `copy` work on an external target outside any graph |
| `CgFrameClock` | The frame's time in double seconds and its index, advanced once per host frame; every pass's `cg_Time`, narrowed to a float only there (`CgPassConstants.time`). CPU code never keeps clock time in a float |
| `CgWarmBudget` | The CPU milliseconds a frame warm-ups may take (`crystalgraphics.warmBudget`, 4): `CgPipeline.precache`, `CgMaterial.precache` and `CgVfxSystem`'s queue start work only while it allows, so a warm-up spreads over frames. Unlimited until the graphics start (`CgGraphicsLifecycle.init`) starts it |
| `CgCpuMeter` | A consumer's CPU nanoseconds: added by its own code from any thread, and by the executor for each compute pass charged with `charged(meter)`, timed as it runs; taken once a frame by whoever budgets it (`vfx.scalability.CgVfxBudget`) |
| `CgGpuBudget` | A consumer's GPU milliseconds a frame and the scale that holds its passes inside them: passes charged with `timed(budget)` are timed through `CgGpuTrace`'s budget slots whatever the trace, and `tickFrame` steps each scale |
| `CgViewFrustum` | AABB and sphere tests against a view-projection: the world renderer culls by it, and `CgCanvas.visible` |
| `draw/` | Pipelines, material bindings, instance kinds, chunks, pass constants, the batcher — what a recorded draw is made of. Its own guide |
| `graph/` | Recordings, the frame graph, the frame builder and the executor. Its own guide |
| `mesh/` | `CgMeshStore` (where meshes' GPU copies live: placed per frame, uploaded before the first pass inside `cgBeginTransfer` brackets, kept content then staged bytes, so on Vulkan the copies run on the transfer queue and the frame's queue waits for them at its next pass, drawn with base-vertex calls, the vertex stage pulling its vertices, or a run of them of one format as one multi-draw; a draw unplaced in the prologue throws), `CgMeshPool` (one vertex format's vertex buffer and index buffer, grown by copy), `CgOffsetAllocator` (O(1) ranges, ported from Aaltonen's OffsetAllocator) |
| `stage/` | `CgRenderStage`: the points consumers register at, by phase (`PREPARE`, `OPAQUE`, `SURFACES`, `TRANSLUCENT`, `OVERLAY` per view of the scenes a registration reaches; `HUD`, `SCREEN` once a frame). `CgStageFrame`: what a renderer records with (its view, camera, target, recording, `constants()`, `depthPyramid()`). `CgStageFiring`: the engine's side of one firing. `CgDirectionalLights`: directional lights besides the host's sun, the highest priority (then the brightest) taking `cg_SunDirection` in `CgWorldAtmosphere` and its collection `directional_light` |
| `host/` | `CgStageHost`: what a host fires (`WORLD_OPAQUE`, `WORLD_TRANSPARENT`, which nothing registers on and the scene renderer runs inside; `fireOverlay` for the GUI stages; `define` a mod's own) and the frame it fills (`frame(stage)`: timing, target, camera, environment, textures). `CgHostEnvironment`, `CgHostTextures`, `CgWorldAtmosphere`: the host world's sky, settings and textures |
| `view/` | `CgView`: one camera's picture of one scene, frame after frame, as Unreal's `FSceneView` (`CgView.main()`; `create(name)` an anaglyph eye or a portal of the client scene; `of(scene)` a scene of one's own; `unkept()` for a repeat firing), drawn by its host's callbacks or whole by `renderInto(target)`. Per view: `textures()` (`CgSceneTextures`, what this frame's stages hand on), `publish/read` (`CgViewKey`), `showFlags()` (`CgShowFlags`), `flag(var)`/`override(var, value)` (the renderer's switches), `hide`/`showOnly` (Unreal's hidden and show-only components, what rides one included; the gather asks `sees(primitive)`), `copySettings(view)`. `CgViewState`, its `FSceneViewState`: each temporal history and what one draw keeps for the next, as a renderer's record made at its first ask (`get(Key)`). Never a renderer's field, and never keyed by which firing of the frame it is |
| `scene/` | The scene: primitives kept until removed, as Unreal's `FScene`. `CgScene` (`client()`, or one of your own) makes components; `once()` takes rows for this frame only. Lights (`pointLight()`, `spotLight()`, `tubeLight()`, `onceLights()`, `dynamicLights`), haze (`haze()`) and height fog (`heightFog()`) are components like the rest. `renderer/`: `CgSceneRenderer`, the scene drawn through a view, and its features. Its own guide. `component/`: `CgPrimitiveComponent` and its kinds (`CgMeshComponent`, `CgInstancedMeshComponent`, `CgDynamicComponent` over a `CgDynamicPrimitive` and its `CgMeshCollector`), `CgScenePrimitives` the spawned set and the gather: frustum, reach, levels, each primitive's world box kept until it moves. `gpu/`: `CgGpuScene`, the records kept on the GPU (Unreal's GPUScene), a slot per primitive or instance placed by a tile and a model within it, its previous transform beside it; every pass binds them (`cg_SceneObjects`) and an object id with the scene bit names one, decoded by `cg_env.glsl`'s `cg_ObjectData`. `visibility/`: `CgViewVisibility`, what a view sees of a scene, made once a draw of a frame at the first ask and kept in the view's state (Unreal's `FViewInfo` from `InitViews`); a world stage's firing asks for the client scene's before its callbacks; `CgInstanceCulling`, its instanced rows culled per instance on the GPU against the frustum and a depth pyramid (`instance_cull.compute`), kept ids and a count per row. `batch/`: `CgMeshBatches`, a view's rows (Unreal's `FMeshBatch`), each with its distance and sort key; `CgCachedCommands`, a persistent primitive's commands per pass type, kept until its material, mesh or pass settings change (Unreal's cached mesh draw commands). `pass/`: `CgViewPasses`, a view's commands per pass type, built once a frame and recording from the visibility's rows (`CgDrawCommands`, no chunk) and handed to a raster pass with `add(...)`. `CgDecalComponent`: a decal material's box, its sort order and fades. `CgSceneCaptureComponent`: a camera drawing the scene into a render target (Unreal's `USceneCaptureComponent2D`), run before the scene's first view of a ring frame (`CgScenePrimitives.updateCaptures`, which `CgStageHost` calls before a firing begins). `CgQuadComponent`: UI in the world, a quad turned or facing the camera, drawn with a material, a picture the canvas paints (`fill`, `paint`, `widget`; painted in `updateCaptures`, at its height on screen, on change) or glass (`backdropFilter`, reading `CG_SCENE_COLOR_BLURRED`). `CgLabelComponent`: kept text, a held label of the renderer's `CgCanvasLabels` (`heldLabels`, slots that never move). `capture/`: `CgSceneCaptureSpawner`, a sequence's `capture` spawnable. `sort/`: `CgSortLayer`, `CgSortKey` |
| `debug/` | `CgDebugDraw`, Unreal's `DrawDebugLine` family: any thread, a frame, a duration or until cleared, depth-tested or `foreground()`. `CgDebugBatch`, a frame's segments or see-through faces (origin-relative, faces sorted back to front by piece), which `CgCollisionDebug` draws through too; `CgLineSink`, where shape outlines (`CgShapeLines`) write. Their materials are `shaders/debug/lines*.shader`, `#domain surface`: a scene row with a `#domain global` material draws nothing |
| `target/` | `CgRenderTarget`: a texture drawn into at run time, Unreal's `UTextureRenderTarget2D`: made in code or from a settings file's `render_target` block (`CgMaterialRegistry.texture` answers its texture by path), its ten formats, clear colour and generated mips; `clear()`, `drawMaterial(material)` over a canvas quad, `readback(sink)` async only. `CgView.renderPicture`'s picture is one |
| `meshpass/` | Mesh passes, as Unreal's `EMeshPass` and `FMeshPassProcessor`: a `CgMeshPassType` (an id, a `CgPassLayout` of attachments, a `CgMeshPassProcessor` that turns a `CgMeshBatch` into commands through `CgMeshPassCommands`), registered once; `registerPerFrame` for a type whose answer changes each frame (velocity). `CgPrimitiveRelevance` (which engine passes a material reaches), `CgPrimitiveInfo` and `CgPrimitiveFlag` (a consumer's flag on a primitive, read by its processor), `CgCustomDepth` (named stencil values, allocated once). `engine/`: `CgEnginePasses`, the engine's own types: depth, base, translucent, emissive, distortion, custom depth, custom data, velocity, decal. Run a type from a stage with `CgStageFrame.meshPass(type)` |
| `precache/` | `CgPipelinePrecache`, `CgPipelineList`: pipelines built ahead of use. Its own guide |
| `post/` | The post chain: `CgPost` (a view's effects at points, each `(ctx, input) -> output`), `CgPostRenderer` (what the scene renderer runs, in the frame's order), bloom, the composite and the looks. Its own guide |
