# material — CrystalShader Material Surface

> Root guide: [`CrystalGraphics/AGENTS.md`](../../../../../../../../../AGENTS.md)  
> Internal parse/compile implementations: [`parse/CLAUDE.md`](parse/CLAUDE.md)

## What This Package Is

The thin public surface of the CrystalShader `.shader` file format pipeline, plus the
runtime property value object used by `CgMaterial` and callers.

The bulk of the parse, compile, and GLSL-generation implementation lives in
`material/parse/`. See [`parse/CLAUDE.md`](parse/CLAUDE.md) for the full class map.

Implementation tasks:
- **T7** — `CgShaderParser` pass-aware dispatch, `CgParsedShader` (pass-based schema), `CgParsedPass`, `CgShaderParseException`
- **T8** — `CgMaterialShaderCompiler` per-pass compile + depth auto-gen, `CgMaterialShaderMap`'s ProgramKey cache

## Class Map — This Package (`material/`)

| Type | Role |
|------|------|
| `CgMaterialShader` | The shader asset, Unreal's `UMaterial`: source, parse (`ensureParsed`, `getLastParsed`), what the source reads (`readsSceneDepth`/`readsSceneColor`/`discards`), `renderType`/`renderQueue`, `dirty`, hot reload, `revisionNumber`. `recompile()` / `submitRecompile()` (sources made on a worker, `pollPending` commits) build a new `CgMaterialShaderMap` and swap it in whole. `getOrCompile`, `precacheVariant`, `hasCompiledPass`, `variantError` and `engineBuffers()` answer from the committed map. Also the GL seam until GL3: `prepare` (preprocess + `checkSource`) and `wire` (blocks and samplers to their points). `delete()` is the registry's. |
| `CgMaterialShaderMap` | The programs of one parse, Unreal's `FMaterialShaderMap`: each pass × keyword set (`ProgramKey`), the template properties block and the engine tokens' buffers they were generated against. Never stale: a recompile replaces it. `get` compiles a variant on a miss; `precache` submits one without waiting, its sources made on a worker; the depth pass is generated by `autoGenDepth` (late, for a forward-only compile). Package-private. |
| `CgMaterialShaderRegistry` | Singleton path→asset cache. `getOrCreate(path)` returns the shared `CgMaterialShader` instance, creating it on miss (marked dirty); `getOrCreate(path, state)` keys it by path and the state's blend and clip as well (`CgMaterialShader.getState`, applied to every parse by `CgParsedShader.withState`), a state of cull or depth write alone answering the shader's own asset. `reloadAll()` marks all assets dirty — materials detect revision change on next `bind()`. `deleteAll()` deletes all assets and clears cache; called directly by `CgEngineLifecycle.shutdown()`. `resetForTest()` is a package-private reset for unit tests. |
| `CgMaterialProperty` | Mutable runtime property object. Holds the declaration (`name`, `displayName`, `type`, `rawDefault`), the current float/int/sampler value, and self-binding logic. The value setters (`set`, `setInt`) return whether the value moved, bit for bit. `fromDecl(name, displayName, typeName, rawDefault)` creates and eagerly parses the default. `copyWithDefaults()` returns a fresh independent clone with the default value applied — used by `CgMaterial.onShaderRecompiled()` to initialise per-instance property stores. `applyToSampler(CgShaderBindings)` flushes sampler value to shader uniforms (sampler-only). `writeToUbo(CgBufferWriter)` writes non-sampler value into the material UBO. `addToFormatBuilder(CgBufferFormat.Builder)` registers the field in the UBO layout. `set(...)` overloads for float/vec2/vec3/vec4; `setInt(int)` for INT; `setTexture(unit, CgTexture)` for sampler types. `resetToDefault()` restores the parsed default. Inner enum `Type` maps property type names to GLSL names and component counts; `isSampler()` is the canonical discriminator. |
| `CgMaterialProperties` | Partitioned view of a material's full property list — splits into UBO-eligible (non-sampler) and sampler properties at construction. Implements `CgShaderBindings` for name-based property writes from `CgMaterial.applyProperties()`; `consumeBlockChanged()` answers whether a block-backed value actually moved, which is all that dirties the block (a sampler never does). `propsByName` HashMap built during construction/rebuild for O(1) name lookup. `rebuild(List<CgMaterialProperty>)` repopulates all internal state in-place — called on hot-reload to avoid reallocation. `buildUboFormat()` builds the `CgBufferFormat` for `CgMaterialBlock`. `writeUboProps(CgBufferWriter)` uploads all non-sampler values. `applySamplerProps(CgShaderBindings)` binds all sampler values. `EMPTY` sentinel for contexts needing a non-null default. |
| `CgMaterialBindingsAdapter` | **Deprecated stub** — logic fully absorbed into `CgMaterialProperties`. |

## Compiler Output Format

### Vertex shader generation sequence (steps 1–14)

1. `#version 450 core`, the one target (`CgMaterialShaderCompiler.VERSION`) on GL and, through shaderc, Vulkan; the
   vertex stage enables `GL_ARB_shader_draw_parameters`: `cg_env.glsl` reads a draw's bases
2. `#define CG_VERTEX_STAGE 1`
4. `#define CG_OBJECT_BUFFER_BINDING <CgBindingPoints.OBJECT_DATA>` + `#define CG_FRAME_BLOCK_BINDING <CgBindingPoints.FRAME_DATA>`
5. `#include "crystalgraphics:shaders/env/cg_env.glsl"`
5a. **Vertex pulling** — `CgGlslEmitter.emitVertexDeclarations(vertexFormat)` declares the store's words (`CgVertexWords` at `CgBindingModel.VERTICES`) and a global per attribute of the resolved `CgVertexFormat` (from `shader.shaderType()` via `CgVertexFormat.forShaderType()`); `emitVertexFetch` writes `cg_FetchVertex()`, which `main` calls first. The skinned variant fetches after `bones.glsl`, either width by `CG_BONES_WIDE`. Not present in fragment source.
6. `CgMaterialBlock` UBO block (emitted via `CgGlslEmitter.emitUbo()` when non-sampler properties exist; declared at `CgBindingPoints.MATERIAL_PROPERTIES_UBO`'s binding)
7. Sampler property uniform declarations (`uniform sampler2D/sampler2DArray/sampler3D/samplerCube <name>;` — one per sampler property)
8. User-attached SSBO buffers (emitted by `CgGlslEmitter`)
8. User-attached UBO blocks (emitted by `CgGlslEmitter`) — path-independent
8a. `Buffers { }`: the structs its buffers name, then each buffer's reader (`CgBufferReaders.reader`) — a storage block wired to `CgBindingPoints.MATERIAL_BUFFERS_SSBO + i`. The fragment stage the same
9. `struct v2f { <v2fStructBody> };`
10. `flat out int cg_InstanceId;`
11. v2f interface block (`out _CgV2fBlock { <fields> } _cg_v2f;`)
12. Global declarations (verbatim `globalDecls` from parsed shader)
13. User vertex function (`void vertex(out v2f o) { <vertexBody> }`)
14. Generated `void main()` — assigns `cg_InstanceId = CG_INSTANCE_ID` (so the fragment sees the batch's base too), calls `vertex(_v2f_local)`, copies fields to `_cg_v2f.<name>`

### Fragment shader generation sequence (steps 1–13)

1. `#version 450 core` (no `CG_VERTEX_STAGE`)
3. `#define CG_OBJECT_BUFFER_BINDING` + `#define CG_FRAME_BLOCK_BINDING`
4. `#include "crystalgraphics:shaders/env/cg_env.glsl"`
5. `CgMaterialBlock` UBO block (when non-sampler properties exist)
6. Sampler property uniform declarations
7. User-attached SSBO buffers
7. User-attached UBO blocks
8. `struct v2f { ... };`
9. v2f interface block (`in _CgV2fBlock { <fields> } _cg_v2f;`)
10. Global declarations
11. `out vec4 _cg_fragColor;`
12. User fragment function (`void fragment(in v2f i, out vec4 fragColor) { <fragmentBody> }`)
13. Generated `void main()` — reconstructs `v2f _v2f_local`, calls `fragment(_v2f_local, _cg_fragColor)`

## `CgGlslEmitter` — GLSL Generation Details

### SSBO output shape

```glsl
struct StructName { type field; };
layout(std430) readonly buffer BufferName { StructName _cg_structNameArr[]; };
#define MACRO_NAME(n) _cg_structNameArr[n]
```

### UBO output shape

```glsl
layout(std140) uniform BlockName { type field; };
```

No struct, no instance name, no macro. Block name = `buffer.getName()`. Path-independent.

## Key Design Rules

- **No GL calls** in parser or compiler — pure string transforms.
- **Always pass `resourcePath`** — all `CgShaderParseException` messages include `[path]` prefix.
- **Properties block is optional** — `CgPropertiesParser.parse()` returns an empty list if absent.
- **Comment lines skipped** in `v2f` body and `Properties` block.
- **`#` directive passthrough** — preamble `#`-lines are collected by `CgStructureParser.parsePreambleDirectives()` and prepended to `globalDecls`; the compiler's `partitionGlobalDecls()` emits them right after `#version`.
- **Auto-inject extensions** — `CgGpuType.requiredExtension()` drives automatic `#extension` emission for `INT64`/`UINT64` fields; throws `CgPreprocessorException` if the capability is absent.
- **vec3 is banned from Properties** — `CgPropertiesParser` throws `CgShaderParseException` and `CgMaterialProperty.fromDecl()` throws `UnsupportedOperationException` when `vec3` is used as a property type. Root cause: STD140 pads `vec3` to 16 bytes but the GLSL compiler places the next field 12 bytes later, causing a 4-byte offset mismatch. Use `vec4` instead.

## Keyword Variant Internals

`CgMaterialShaderMap` holds one GL program per unique (passName × keyword-set) combination, for one parse:

- `ProgramKey(String passName, Set<String> keywords)`; keyword equality is set-based.
- The no-keyword variant of each pass is compiled by `recompile()` into a new map; keyword variants on the first
  `getOrCompile(passName, keywords)` or `precacheVariant`.
- The generated depth pass is kept under `ProgramKey("Depth", emptySet)`.

**No shadow pass.** A `ShadowCaster` pass or a `CastShadows` tag is a parse error: the world's shadows are
ray-traced from each pixel (`CgWorldLights`, Unreal's MegaLights), so nothing draws from a light's side.

**Depth auto-generation (`CgMaterialShaderMap.autoGenDepth`, from `recompile()`):**
- Runs when `renderQueue < TRANSPARENT_THRESHOLD && no explicit Depth pass authored`.
- Every opaque material needs a correct depth variant.
- Finds the first Forward-lit pass → calls `CgMaterialShaderCompiler.compileDepthAutoGen(...)`.
- Three-case GLSL: (1) simple vertex → minimal `CG_MATRIX_MVP` transform; (2) complex vertex → forward body verbatim; (3) alpha-clip → forward vertex + forward fragment (preserves `discard`).
- On GL link failure: logs an error and continues without a depth variant — non-fatal regardless of first/hot-reload.
- On success: stored as `ProgramKey(CgRenderPassVariant.DEPTH.lightModeName(), emptySet)`.

**Compile flow for a keyword variant:**
1. `CgMaterial.enableKeyword("NAME")` adds the name to `CgMaterial.enabledKeywords`.
2. `CgMaterial.bind()` calls `cgMaterialShader.getOrCompileForwardPass(enabledKeywords)`.
3. `getOrCompileForwardPass()` resolves the first Forward pass name, then calls `getOrCompile(passName, keywords)`.
4. `getOrCompile()` asks the committed map, which answers a hit at once.
5. On a miss the map generates the variant (`CgMaterialShaderCompiler.compile(parsed, pass, buffers, block, CompileConfig(keywords))`), links, wires and keeps it.

**Hot-reload interaction:**
- `recompile()` builds a new map and, once its passes link, deletes the old one.
- `revisionNumber` increments so `CgMaterial` instances detect the change on the next `bind()`.
- `CgMaterial.onShaderRecompiled()` clears `wiredToMatPropsUbo` so the per-instance UBO is
  re-wired to any newly compiled keyword variants on their first use.

**Pre-compile `enableKeyword()` path:**
`enableKeyword()` may be called before the first `bind()`. If `cgMaterialShader.getLastParsed() == null`
(i.e. not yet compiled), `enableKeyword()` calls `cgMaterialShader.recompile()` eagerly to
populate `featureNames` for validation.

## Programs (`CgShader`, formerly `material`)

What a material's pass and keyword set, or a kernel, compiles into: the program as written
(`CgGlslCompiler.compileExplicit`) that its device pipelines are built from. Not API: a consumer's shader is a material
(`CgMaterial`) or a kernel (`CgKernel`); there is no public way to compile GLSL text or set a uniform by name (rhi SH9,
Unreal's material and global shaders).

### Class map

| Class | Job |
|---|---|
| `CgShader` | A material program from generated sources: `compile` (now) or `submit` (on a worker), `isReady`, `isCompiled`, `getLastCompileError`, `explicit()`, `sceneReads()`, its modules on a device (`deviceModule`), `delete`. A failure is kept, never thrown, but by `explicit()` |
| `CgShaderCompile` | A compile under way: on a job worker where the installed compiler compiles on any thread (shaderc), else run by the first thread that asks (the native compiler, which needs the device's context) |

### Invariants

- `format` places the vertex inputs: attribute `i` at location `i`; null where the source places them.
- The owner of a `CgShader` deletes it: a material's map. A compile still running when it is deleted finishes unread.
- What a program samples of the scene is its own layout's answer (`sceneReads`), so a keyword variant answers for
  itself.
