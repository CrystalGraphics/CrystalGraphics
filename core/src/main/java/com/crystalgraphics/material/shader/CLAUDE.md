# material/shader — reading a `.shader` and writing its GLSL

> Parent package: [`material/CLAUDE.md`](../CLAUDE.md) · Format: [`docs/MATERIAL_FORMAT.md`](../../../../../../../../../docs/MATERIAL_FORMAT.md) ·
> Authoring: [`docs/SHADERS.md`](../../../../../../../../../docs/SHADERS.md)

A `.shader` file in the material format becomes a **spec** (`CgShaderSpec`: what the material is) and, per pass and
keyword set, a **program** (`CgGlslProgram`: GLSL 4.50 vertex and fragment source). No GL call anywhere here.

```java
CgShaderSpec spec = CgShaderSpec.read(source, "mymod:shaders/glass.shader");      // throws CgShaderError
CgShaderPass forward = spec.pass(CgRenderPassVariant.FORWARD);
CgGlslProgram p = CgGlslWriter.write(spec, forward, attachedBuffers, materialBlock, Set.of("MOSS"));
CgGlslProgram depth = CgGlslWriter.writeDepth(spec, forward, attachedBuffers, materialBlock, Set.of());
```

## Three layers, one direction

| Package | Owns | Reads |
|---|---|---|
| `syntax/` | The lexer (`CgShaderTokens`), the tree (`CgShaderSyntax`: directives, blocks, structs, functions, declarations, `Step`s), each block's grammar (`CgSettingsGrammar`, `CgKeywordGrammar`, `CgPropertyGrammar`, `CgRenderStateGrammar`), `CgCodeScan` (what code names) and `CgShaderError` | text |
| `material.shader` | The domains (`SurfaceDomain`, `GlobalDomain`, `PostDomain`, `UiDomain`) reading the tree into passes through `SpecReader`/`SpecBuilder`; the templates (`CgShaderTemplates`: `.factory`, `.primitive`); the spec, its passes and permutations; the writer | `syntax` |
| `glsl/` | GLSL text for blocks: uniform and storage blocks, the arena, a buffer's reader, a vertex format's declarations and fetch (`CgGlslBlocks`) | nothing here |

`compute.parse` reads `.compute` files on the same `syntax` package and its `CgShaderError`; nothing in `syntax`
names a material or a kernel.

## Rules

- **One read, facts decided once.** A pass's facts (`clips`, `simpleVertex`, `namesGlow`, what the vertex stage
  names, ...) are fields set when it is built, from tokens. The writer asks; it never scans GLSL text again.
- **Every error is placed.** `CgShaderError` reads `path:line:column: why`, at the token that is wrong; a problem of
  the whole file reads `path: why` and `line()` is 0. Throw `tokens.error(i, why)` or `CgShaderError.at(text, offset,
  why)`; never search the source for a quoted word to place one.
- **No intermediate text.** A domain builds `CgShaderPass`es directly; nothing is lowered to another format and read
  again.
- **The writer emits, it does not edit.** Sections are appended in order; no `insert` into what was written. A wrapped
  `main` (the volume and layer targets) is the generated one named `_cg_main` from the start.
- **Each helper is compiled into the stages that reach it** (`CgShaderPass.Code.stages`): a function only `surface()`
  calls sits behind `#if !defined(CG_VERTEX_STAGE)`.
- **An engine buffer is reached, never named**: a factory or a primitive brings `quad`, `curve`, ...; code naming
  `QUAD_DATA` or a `CG_QUAD_*` macro without it fails naming the template to use.
- **Refused, with the replacement named**: `Pass`, `Tags`, `Queue`, `SubShader`, `#pragma`, `#type`, `#version`, a
  second `#domain`, a `vec3` property (std140 pads it: `vec4`), a property declared twice, more than 31 keywords
  (a material's keyword mask), more than `CgShaderPermutations.MAX_VARIANTS` switched combinations.

## The passes a surface material gets

| Pass | When | What the writer does |
|---|---|---|
| Forward | always | the factory's vertex, the material's `vertex()` and `surface()`, each output to its hook (`cg_Clip`, `CG_GLOW`, the surface normal, ...) |
| Emissive | `surface()` names `emissive` | codeless: draws the Forward pass's code (`copiesForward`) with `CG_EMISSIVE_PASS`, unlit, fog mode 2; folds into the Forward draw where `emissionMerge()` says (`SAME_BLEND`, or `ADDED` under a premultiplied blend), into the HDR scene where `sceneFolds()` |
| Distortion | `surface()` names `refraction` | `CG_DISTORTION_PASS`, blend `DISTORTION_BLEND`; neither lit nor fogged |
| Depth | generated by `writeDepth` for an opaque queue | a simple vertex projects `cg_Position` alone; any other keeps the Forward vertex; a pass that clips keeps its fragment so `discard` fires |

- **Depth modes** (`DepthMode`): `BlendMode Masked` or `ClipDepth On` is `CLIP` (Forward writes depth, `cg_Clip`
  discards below `MaskClip`, else 0.5); `DepthPrepass On` is `PREPASS` (a translucent queue only: the blend writes
  no depth, `cg_Clip` is empty there and discards then returns under `DEPTH_PREPASS`; vertex stages
  `invariant gl_Position`).
- **The HDR scene's decode** ends a single-output Forward `main`: `cg_SceneDecode`, after light and fog;
  `ColorSpace Linear` encodes for the host's target instead.
- **Dimmed by the media**: a transparent queue below Overlay reading the object record ends its `main` with
  `cg_MediaTransmit`, unless `Media Off` or it names `CG_VOLUME_DEPTH`.
- **Under a material state** (`withState`): the Forward passes take its blend and clip as if authored; a blend
  without `clip()` drops a Clip mode (Unreal's Masked override); a `SUBTRACT` glow adds.
